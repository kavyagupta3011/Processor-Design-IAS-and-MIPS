# Processor-Design-IAS-and-MIPS


Two projects implemented as part of the Computer Architecture coursework. These projects demonstrate the implementation of key concepts in IAS and MIPS architectures through Python and assembly programming.

---

## **Assignment 1: Armstrong Number Checker**
- **Objective:** To determine if a given number is an Armstrong number using the IAS instruction set.
- **Implementation:**  
  - High-level code written in C, with assembler and processor logic implemented in Python.  
  - Custom instructions added:  
    - **LEN Instruction:** Calculates the number of digits in the number.  
    - **POWER Instruction:** Raises digits to the power of the number of digits.
  - Outputs `1` for Armstrong numbers and `0` otherwise.  
- **Result:** Successfully verified Armstrong numbers like `153` and non-Armstrong numbers like `37`.

---

## **Assignment 2: MIPS Processor Design**
- **Objective:** To design a MIPS processor and implement the following programs:  
  1. **Sum of Squares of Digits:** Calculates the sum of squares of the digits in a number.  
  2. **Factorial:** Computes the factorial of a given number.  
  3. **Maximum Element in an Array:** Finds the maximum value in an array.  
- **Implementation:**  
  - Programs written in MIPS assembly and simulated using the MARS simulator.  
  - Processor stages include Instruction Fetch, Decode, Execute, Memory, and Write Back.  
  - Control signals and ALU operations handled through custom logic.  
- **Result:** Successfully tested the programs for inputs like `31` (sum of squares), `5` (factorial), and `[88, 3, 66, 723, 9]` (maximum element).

---

## **Key Features**
- Hands-on implementation of IAS and MIPS architecture concepts.  
- Custom instruction and processor design for specific tasks.  
- Simulations verified against theoretical results.
